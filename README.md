# Formula 1 Website

## Descripción del Proyecto
Este proyecto es un sitio web dedicado a la **Fórmula 1**, que proporciona información actualizada sobre el calendario de carreras, pilotos y equipos de la temporada **2025**. El sitio incluye:

- Calendario completo de carreras con fechas, banderas de países e imágenes de circuitos.
- Perfiles de todos los pilotos con sus respectivos equipos y banderas nacionales.
- Información detallada de cada equipo, incluyendo pilotos y monoplazas.
- Noticias y características destacadas del mundo de la F1.

## Estructura del Proyecto

El proyecto contiene las siguientes páginas principales:

- **index.html**: Página principal con noticias destacadas.
- **schedule.html**: Calendario completo de carreras.
- **drivers.html**: Listado de todos los pilotos.
- **teams.html**: Información detallada sobre los equipos.

Además, incluye los siguientes archivos de estilos y scripts:

- **styles.css**: Estilos principales del sitio.
- **schedule.css**: Estilos específicos para la página del calendario.
- **driver.css**: Estilos para la página de pilotos.
- **team.css**: Estilos para la página de equipos.
- **script.js**: Funcionalidades JavaScript para la interacción del sitio.

## Características Principales

### Diseño Responsivo
- Adaptación a diferentes tamaños de pantalla (escritorio, tablet, móvil).
- Uso de **CSS Grid** y **Flexbox** para diseños modernos y fluidos.
- **Media queries** para ajustes específicos en dispositivos móviles.

### Interactividad
- Efectos **hover** en tarjetas y elementos interactivos.
- Navegación con **resaltado de la página activa**.
- Generación dinámica de contenido mediante JavaScript.

### Tipografía Personalizada
- Uso de la fuente personalizada **"Alphacorsa"** para los títulos.
- Jerarquía visual clara con diferentes tamaños y pesos de fuente.

### Visualización de Datos
- Tarjetas informativas para cada carrera, piloto y equipo.
- Uso de **banderas** para representar nacionalidades.
- **Códigos de colores** para identificar fácilmente a los equipos.

## Tecnologías Utilizadas
- **HTML5**: Estructura del sitio web.
- **CSS3**: Grid, Flexbox, animaciones y diseño responsive.
- **JavaScript**: Manipulación del DOM, eventos y contenido dinámico.
- **Bootstrap 5**: Componentes modernos y responsivos de navegación.
- **Fuentes personalizadas**: Tipografía Alphacorsa para títulos destacados.
